## 무엇인가

macOS용 "잠깐 여기 둘게" 선반입니다. 파일을 드래그하기 시작하면 오른쪽 가장자리에서 나타나고, 하마 입에 놓으면 잠시 보관합니다. 필요할 때 다시 꺼내 쓰고, 입이 비면 다시 숨습니다.

파일을 관리하거나 가져가지 않습니다. "곧 쓸 몇 개의 파일"에게 눈에 보이는 임시 자리를 줄 뿐입니다. 예를 들어:

- **파일 보낼 때** (카카오톡, 메일, Slack): 보낼 파일을 입에 모아 두었다가 채팅창으로 한 번에
- **디자인·집필 중**: 스크린샷을 일단 입에 넣고, 나중에 Figma나 문서로
- **정리 중**: 여러 폴더에서 고른 파일을 잠시 모았다가 목적지로 한 번에

## 기능

- 🐡 **드래그하면 나타남**: 파일을 드래그하기 시작하면 오른쪽 가장자리에서 슬라이드
- 👄 **입으로 받기**: 하마 얼굴 위에서 놓으면 보관. 중복 파일은 자동 제외
- 📚 **관리 도구가 아닌 선반**: 한 줄에 파일 하나, 썸네일 + 이름. 파일이 늘면 입이 세로로 커짐 (스크롤 없음)
- 🫥 **비면 숨음**: 화면 가장자리로 돌아갑니다
- 🖱 **꺼내기**: 밖으로 드래그하면 **복사** (원본 유지). 클릭 선택, Space 훑어보기, 더블클릭 열기
- 🎯 **다중 선택**: ⌘ / ⇧ / 빈 곳 드래그로 선택, 한꺼번에 꺼내기
- 🎨 **두 가지 스킨**: 카툰(검은 하마) / 심플(macOS 유리), 메뉴 막대에서 전환
- 📍 **원하는 곳에 두기**: 상단 바를 드래그해 이동, 위치 기억
- 🧠 **작은 움직임**: 눈 깜빡임, 귀 흔들림, 마우스를 따라오는 눈동자 (카툰)
- ⚙️ **설정 창**: ⌘, 로 언어, 로그인 시 실행, 업데이트 확인
- 🌐 **5개 언어**: 한국어 / English / 简体中文 / Español / 日本語, 언제든 전환
- 🔄 **업데이트 확인**: 클릭 한 번으로 GitHub 최신 버전을 확인하고 다운로드로 이동
- 💸 **완전 무료**: 인앱 결제·구독·광고·계정 없음
- 🔒 **기본 로컬**: 업로드·계정·텔레메트리 없음. 네트워크는 직접 「업데이트 확인」을 누를 때만

## 개인정보

**이 프로젝트의 가장 중요한 설계 결정: 기본은 로컬, 그리고 무료입니다.**

- **기본적으로 네트워크 없음**: 클라우드·분석·크래시 전송·계정 없음
- **「업데이트 확인」만 통신**: 직접 누를 때만 GitHub 공개 API에 최신 버전을 묻습니다. 파일·경로·기기 정보는 보내지 않습니다. 누르지 않으면 완전 오프라인으로 모든 기능이 동작합니다
- **업로드 없음**: 메모리에 저장하는 것은 파일 **경로**뿐. 앱을 종료하면 목록이 비워집니다
- **파일을 건드리지 않음**: 밖으로 드래그하면 **복사**. 원본은 삭제·이동·이름 변경되지 않습니다
- **오픈소스**: 로직은 Swift 6개 파일뿐, 줄 단위로 검토할 수 있습니다
- **외부 의존성 없음**: Apple AppKit만 사용. 패키지 관리자도 바이너리 의존성도 없습니다
- **요금 없음**: 결제·구독·광고 없음, 가입을 요구하지도 않습니다

한 줄로: 경로만 보관하고, 내용은 건드리지 않으며, 직접 업데이트를 확인할 때만 통신합니다.

## 설치

### 방법 1: 다운로드 (권장)

[Releases](https://github.com/wunankun/HippoShelf/releases/latest)에서 `HippoShelf-1.9-universal.zip`(약 1.9 MB, Intel / Apple 실리콘 공용)을 내려받아 압축을 풀고 `HippoShelf.app`을 응용 프로그램 폴더로 드래그하세요.

- **첫 실행:** 앱을 우클릭 → 열기 → 다시 열기 (로컬 서명만, 공증 없음).
- "손상되었기 때문에 열 수 없습니다"가 뜨면:
  ```bash
  xattr -dr com.apple.quarantine /Applications/HippoShelf.app
  ```
- 체크섬(선택): `shasum -a 256 HippoShelf-1.9-universal.zip` 결과를 Release 페이지의 `.sha256` 파일과 비교.

> 모든 릴리스는 GitHub Actions가 소스에서 빌드하며([release.yml](.github/workflows/release.yml)), `.sha256` 파일을 함께 제공합니다.

### 방법 2: 소스에서 빌드

> Command Line Tools가 이미 있으면 3단계로 건너뛰세요.

**1단계: 환경 확인**

```bash
sw_vers -productVersion   # 13.0 이상 필요
xcode-select -p           # 경로가 나오면 도구 설치됨
swiftc --version          # 버전이 나오면 컴파일러 OK
git --version             # 버전이 나오면 git OK
```

**2단계: 없는 것만 설치**

| 보이는 화면 | 할 일 |
| --- | --- |
| `xcode-select -p`가 `unable to get active developer directory` 오류 | `xcode-select --install` 실행 후 설치를 누르고 5~15분 대기 |
| 대화상자가 안 뜨거나 다운로드가 멈춤 | 시스템 설정 → 일반 → 소프트웨어 업데이트 확인, 또는 https://developer.apple.com/download/all/ 에서 수동 다운로드(무료 Apple ID) |
| 설치 후에도 오류 | `sudo xcode-select -s /Library/Developer/CommandLineTools` 실행 후 다시 확인 |
| `swiftc`가 라이선스를 요구 | `sudo xcodebuild -license accept` |
| macOS가 13 미만 | macOS 업데이트 또는 다른 Mac 사용 (13 이상 필요) |
| 관리자 권한 없음(회사 Mac) | IT에 요청하거나 위의 "방법 1" 빌드된 버전 사용 |

**3단계: 빌드**

```bash
git clone https://github.com/wunankun/HippoShelf.git
cd HippoShelf
./build.sh
open HippoShelf.app
```

> 전체 Xcode(수 GB)는 필요 없고 Command Line Tools로 충분합니다. `build.sh`가 arm64와 x86_64를 각각 빌드해 `lipo`로 하나의 유니버설 앱으로 합칩니다.

### 첫 실행

- 처음에는 더블클릭하지 말고 **우클릭 → 열기 → 열기** (로컬 서명, 공증 없음)
- "손상되었기 때문에 열 수 없습니다"가 나오면:
  ```bash
  xattr -dr com.apple.quarantine /Applications/HippoShelf.app
  ```
- Dock에 아이콘은 없습니다. 메뉴 막대의 하마가 본체입니다 (정상)
- 데스크톱 / 문서 / 다운로드에서 처음 놓을 때 권한을 물으면 허용하세요
- 로그인 시 실행: 메뉴 막대 하마 → 「설정」 → 「로그인 시 실행」 켜기 (시스템 설정 → 일반 → 로그인 항목에서도 추가 가능)

## 사용법

- 파일 드래그 → 하마 등장 → 입에 놓기
- 클릭 선택, Space 훑어보기, 더블클릭 열기; ⌘ / ⇧ / 드래그로 다중 선택
- 선택한 파일을 입 밖으로 드래그하면 **복사**되고 선반에서 빠집니다 (원본 유지)
- 오른쪽 귀의 빨간 새 = 비우기; 비면 자동으로 숨습니다
- 상단 바를 드래그해 이동; 위치는 기억됩니다 (⌘S로 언제든 표시)
- 메뉴 막대: 표시/숨기기, 비우기, 스킨, 설정(⌘,), 종료
- 설정에서 언어, 로그인 시 실행, 업데이트 확인을 바꿀 수 있습니다

## 자주 묻는 질문

**Q: 모든 Mac에 Xcode Command Line Tools가 있나요?**
A: 아닙니다. 먼저 `xcode-select -p`를 실행하세요. 경로가 나오면 준비 완료입니다. 오류가 날 때만 `xcode-select --install`(수백 MB)이 필요합니다. Xcode 본체는 필요 없습니다.

**Q: 파일이 많아지면 어떻게 되나요?**
A: 입이 계속 커지고 스크롤은 없습니다. 화면에 안 들어가면 비워 주세요.

**Q: 파일을 삭제하나요?**
A: 아닙니다. 경로만 보관합니다. 밖으로 드래그하면 복사되고, 종료하면 목록만 비워집니다.

**Q: 파일을 업로드하나요?**
A: 아닙니다. 기본적으로 네트워크 요청을 하지 않습니다. 유일한 통신은 「업데이트 확인」으로, 누를 때 GitHub에 버전을 묻는 것뿐입니다(`UpdateChecker.swift`).

**Q: 다중 디스플레이 / 스페이스?**
A: 지원합니다. 이동한 화면을 따라가고 위치를 기억합니다.

**Q: 상업적 사용이 가능한가요?**
A: MIT이므로 가능합니다. 저작권 표시를 유지하세요.

**Q: 왜 하마인가요?**
A: 입이 커서요.
