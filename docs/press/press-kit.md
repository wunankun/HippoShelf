## Long description (100–150 words)

- **EN** — HippoShelf is a small native macOS app for the "I'll need these files in a second" moment. It lives in the menu bar. As soon as you start dragging a file from Finder or your desktop, a drawn hippo's head slides out from the right edge of the screen. Drop files into its big mouth and they stack there, one per row; drag a file out again and it is copied back (the original is never touched), then disappears from the shelf. When the mouth is empty, the hippo slides away. There are two skins (a cartoon hippo and a frosted-glass card), five UI languages, multi-select with ⌘/⇧ or a marquee, Space for Quick Look, and a settings window for language, launch at login and update checks. Everything is local: no accounts, no telemetry, no uploads — the only optional network call is the GitHub update check you trigger yourself.
- **ZH** — HippoShelf 是为"这些文件我一会儿就要用"这个小场景做的一只原生 macOS 小工具。它住在菜单栏里：你从 Finder 或桌面开始拖文件的那一刻，一颗手绘的河马头就从屏幕右边滑出来。把文件丢进它的大嘴，文件会一行一个地叠在嘴里；再把文件拖出去，就是复制回 Finder（原文件从不被改动），同时从置物架上消失。嘴空了，河马就缩回屏幕边。它有两种皮肤（卡通河马、毛玻璃卡片）、5 种界面语言、⌘/⇧ 和框选多选、空格 Quick Look，还有设置窗口（语言、开机自启、检查更新）。全部本地运行：没有账号、没有统计、不上传文件，唯一的联网是你主动点的"检查更新"。
- **ES** — HippoShelf es una pequeña app nativa de macOS para el momento "necesito estos archivos en un rato". Vive en la barra de menús: en cuanto empiezas a arrastrar un archivo desde Finder o el escritorio, una cabeza de hipopótamo dibujada se asoma por el borde derecho. Suelta los archivos en su gran boca y se apilan una fila por archivo; arrástralos fuera para copiarlos de vuelta (el original nunca se toca) y desaparecen del estante. Cuando la boca queda vacía, el hipopótamo se retira. Tiene dos pieles (hipopótamo de dibujos y tarjeta de cristal esmerilado), cinco idiomas, selección múltiple con ⌘/⇧ o marco, Quick Look con la barra espaciadora y una ventana de ajustes (idioma, inicio al arrancar, actualizaciones). Todo es local: sin cuentas, sin telemetría, sin subidas; la única conexión opcional es la comprobación de actualizaciones que tú lanzas.
- **JA** — HippoShelf は「このファイル、あとで使う」という瞬間のための小さなネイティブ macOS アプリです。メニューバーに常駐し、Finder やデスクトップからファイルをドラッグし始めた瞬間、右端から手描きのカバの頭がスライドしてきます。大きな口にファイルを落とすと 1 行ずつ積まれ、外へドラッグすると Finder にコピーされ（元ファイルは一切変更しません）、置き場から消えます。口が空になるとカバは引っ込みます。スキンは 2 種類（カートゥーンのカバ／すりガラスのカード）、UI は 5 言語、⌘/⇧ や範囲選択で複数選択、スペースでクイックルック、設定ウィンドウ（言語・ログイン時の起動・アップデート確認）も備えます。すべてローカル動作で、アカウントもテレメトリもアップロードもありません。通信するのは、あなたが押したときの GitHub のアップデート確認だけです。
- **KO** — HippoShelf는 "이 파일들 잠깐 뒤에 쓸 거야"라는 순간을 위한 작은 네이티브 macOS 앱입니다. 메뉴 막대에 살며, Finder나 바탕 화면에서 파일을 드래그하기 시작하면 오른쪽 가장자리에서 손으로 그린 하마 머리가 미끄러져 나옵니다. 커다란 입에 파일을 놓으면 한 줄에 하나씩 쌓이고, 밖으로 드래그하면 Finder로 복사되며(원본은 절대 건드리지 않음) 선반에서 사라집니다. 입이 비면 하마는 다시 숨습니다. 스킨은 두 가지(카툰 하마 / 유리 카드), UI는 5개 언어, ⌘/⇧ 또는 드래그로 다중 선택, Space로 훑어보기, 설정 창(언어·로그인 시 실행·업데이트 확인)을 제공합니다. 모든 것이 로컬에서 동작하며 계정·텔레메트리·업로드가 없습니다. 유일한 통신은 직접 누르는 GitHub 업데이트 확인뿐입니다.

## Positioning

- Category: menu bar utility / file shelf / drag-and-drop productivity
- Closest alternatives: **Dropover**, **Yoink**, **Unclutter** (all paid); HippoShelf is free and open source, and it is a *hippo*
- Better fit for: people who drag the same 2–5 files around all day (screenshots, PDFs, images for a doc), and anyone who likes small delightful Mac apps
- Not a replacement for: clipboard managers, file managers, cloud storage — it stores paths only, in memory

## Privacy statement

No accounts. No telemetry. No file uploads. The app keeps file paths in memory only and clears them when it quits. The single optional network request is "Check for updates", which asks GitHub's public API for the latest release tag — it runs only when the user clicks it. Source is MIT-licensed and small enough to audit: `Sources/` contains six Swift files and no third-party dependencies.
